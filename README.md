
# Minimarket CLI App

## Project Description
A command-line minimarket application written in C. This project demonstrates the use of pointers, structures, arrays, and functions.

## Features
- Display product catalog and stock
- Purchase products with stock validation
- Display membership data and points
- Update product prices using pointers
- Update product names using structures and `strcpy`
- Redeem 1000 membership points for a 10% discount
- Earn membership points from eligible purchases
- Interactive menu that runs until the user exits

## How to Run
1. Compile `main.c` using a C compiler.
2. Run the compiled program.
3. Select an option from the menu.
4. Follow the instructions displayed in the terminal.
